## Project purpose

Design, develop, test, and document a knowledge-based application that represents knowledge using facts and rules and uses logical inference to answer queries or solve problems in a selected domain.

## Required concepts

1. Facts and predicates representing entities, properties, and relationships.
2. Rules deriving conclusions from logical relationships and conditions.
3. Queries retrieving information and testing relationships.
4. Unification demonstrating term matching and variable binding.
5. Backtracking producing and evaluating alternative solutions.
6. At least one meaningful recursive predicate where appropriate.
7. Lists representing and processing collections.
8. Arithmetic and comparison predicates where required.
9. Knowledge-based reasoning deriving answers from facts and rules.
10. An appropriate user input/output mechanism.
11. Tests covering valid queries, invalid inputs, edge cases, and expected results.
12. Documentation explaining representation, rules, queries, and reasoning.

## Eight stages and deliverables

| Stage | Focus | Required evidence |
|---|---|---|
| 1 | Problem identification and proposal | Proposal and problem specification covering problem, objectives, scope, required knowledge, users, outputs, and suitability of logic programming. |
| 2 | Knowledge representation using facts | Prolog source containing facts and working retrieval queries. |
| 3 | Rules and logical inference | Facts, rules, and demonstrated inference queries tested with different fact combinations. |
| 4 | Unification and backtracking | Working multi-solution queries and an explanation of variable binding and alternative search. |
| 5 | Recursion and lists | Meaningful recursive predicates and tested list-processing functionality. |
| 6 | Arithmetic and advanced rules | Arithmetic, comparisons, multiple-condition rules, and negation as failure **or** cut where appropriate; tested queries and evaluation of the added reasoning. |
| 7 | Integration and testing | Coherent application, organized source, user interaction, requirements testing, and correction of logical errors. |
| 8 | Final report and presentation | Complete report, source, feature demonstration, test results, limitations, improvements, and oral defense. |

## Ten expected submission deliverables

1. Project proposal and problem specification.

5. Implementation of unification, backtracking, recursion, and lists where appropriate.

8. Technical documentation and user instructions.
9. Final project report.
10. Project demonstration and oral defense.

## Submission guidelines

- Work may be individual or in a group.
- Prolog must be the primary language.
- Facts and rules must be meaningful and relevant to the selected problem.
- Demonstrate working queries and explain their results.
- Organize and comment source code clearly.
- Test all major predicates with suitable examples.
- Be able to explain how conclusions are derived.
- Acknowledge external sources and knowledge.
- Submit a **Google Drive video link** explaining the project.
