# Source Register

**Status:** No external medical sources have yet been verified for encoding.

This register is mandatory for externally derived condition–symptom knowledge. Listing an organization as a possible starting point is not a citation and does not authorize encoding a fact.

## Sourcing rules

1. Prefer reputable public-health and clinical reference sources appropriate to the team’s context.
2. Record the exact page or document used, not only an organization’s home page.
3. Record the access date and each relationship supported by the source.
4. Do not invent titles, URLs, quotations, authors, dates, or claims.
5. Distinguish a source-backed association from a simplification introduced for this educational prototype.
6. Do not convert a limited association into a necessary, sufficient, diagnostic, severity, or urgency claim.
7. Reconcile conflicting sources before encoding; document unresolved differences.
8. Acknowledge all external sources in the final report and presentation.
